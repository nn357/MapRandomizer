Save states

This in-game save state option allows creating at most one save state at a time. A save state can be loaded an unlimited amount of times. Any save state is cleared automatically by a regular save (at a save station or the Ship).

  • Unlimited: A save state can be created at any time.

  • Limited: A save state can be created only once, until refreshed by a regular save or load.

Compared to emulator/platform-based save states, the in-game save state option has some advantages:

  • Map tile progress is maintained.
  • Music continues uninterrupted if the track is unchanged.
  • Item collection times and other stats are preserved.
  • The fact that save states are cleared by regular saves can help prevent accidental loads.
  • The "Limited" option, if enabled, forces strategic use of save states.
  • It works for some platforms (e.g FXPAK) that would otherwise be unsupported.
This feature requires 256KB SRAM; FXPAK and most modern emulators support this configuration.
